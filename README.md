# Shell Emulator (Configuration Management)

## Описание
Эмулятор командной оболочки ОС с виртуальной файловой системой (VFS).
Выполняет роль учебного проекта по дисциплине "Конфигурационное управление".

## Структура проекта
- `src/` — исходный код эмулятора
- `tests/` — модульные тесты

## Запуск
```bash
python -m src.main
```
## Этап 2: Конфигурация

Эмулятор поддерживает параметры командной строки и выполнение стартовых скриптов.

### Параметры запуска:
- `--vfs-path <path>`: Путь к физическому расположению VFS.
- `--script-path <path>`: Путь к файлу стартового скрипта.

При запуске выводится отладочная информация о переданных параметрах.

### Примеры использования:

**Интерактивный режим с указанием VFS:**
```bash
python -m src.main --vfs-path "/path/to/vfs"
```
## Этап 3: Виртуальная файловая система (VFS)

Эмулятор поддерживает загрузку VFS из ZIP-архивов или base64-кодированных файлов. Все операции выполняются строго в памяти.

### Команды:
- `vfs-info`: Выводит имя загруженного VFS и его SHA-256 хеш.

### Примеры использования:

**Загрузка ZIP-архива:**
```bash
python -m src.main --vfs-path "scripts/vfs_minimal.zip"
````
## Этап 4: Основные команды

Реализована логика работы с VFS для основных UNIX-команд.

### Команды:
- `ls [path]` — список файлов и папок в указанной директории
- `cd <path>` — сменить текущую директорию
- `pwd` — показать текущий путь
- `wc <file>` — подсчёт строк, слов и байт в файле
- `uptime` — время работы эмулятора

### Примеры использования:

**Запуск тестового скрипта:**
```bash
python -m src.main --vfs-path "scripts/vfs_complex.zip" --script-path "scripts/test_stage4.txt"
```
## Этап 5: Дополнительные команды

Добавлены дополнительные команды для работы с файлами.

### Команды:
- `cat <file>` — вывести содержимое файла
- `rm <file>` — удалить файл из VFS (только в памяти)

### Примеры использования:

**Просмотр содержимого файла:**
```bash
vfs_complex.zip> cat root_file.txt
Root content
```
