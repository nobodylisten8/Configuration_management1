# Shell Emulator (Configuration Management)

## Описание
Эмулятор командной оболочки ОС с виртуальной файловой системой (VFS).
Выполняет роль учебного проекта по дисциплине "Конфигурационное управление".

## Структура проекта
- `src/` — исходный код эмулятора
- `tests/` — модульные тесты

## Запуск
```bash
python -m src.main
